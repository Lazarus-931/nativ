# Starting Server

Nativ's local server runs your installed models. If the bottom of the sidebar already shows a **stop** button, it is running and you can move on to [Your First Chat](/getting-started/first-chat).

## 1. Find the control

Open Nativ and find the circular **play** button at the bottom of the sidebar.

{% image src="/assets/getting-started/starting-server/01-start-server-control.png" alt="Nativ sidebar with the Start Server play button at the bottom" width=240 caption="Use the play button at the bottom of the sidebar to start the server." /%}

## 2. Start the server

Select the **play** button. Wait for it to change to a **stop** button. Loading a larger model can take longer. You can also choose **Start Server** from Nativ's menu-bar menu.

## 3. Check that it is live

Open **Dev → Developer**. A green **Live** status confirms that the server is running.

{% image src="/assets/getting-started/starting-server/02-server-live.png" alt="Nativ Developer page with a green Live server status" caption="Live means the local server is ready." /%}

If it does not become live, read **Server Output** on that page for the latest error. [Server details](/getting-started/server-details) explains the address, port, and common start-up problems.
