# Installation

Install Nativ on a Mac with Apple silicon and macOS 26 or newer.

1. Download the DMG from [Nativ releases](https://github.com/Blaizzy/nativ/releases/latest).
2. Open the DMG and drag **Nativ** into **Applications**.
3. Launch **Nativ** from Applications and follow the first-run setup.

Nativ uses in-app updates, so you do not need to repeat these steps for each release.

If you are developing Nativ rather than installing a release, follow [Build from Source](/getting-started/build-from-source).

Next, [download a model](/getting-started/downloading-models).
