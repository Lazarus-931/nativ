# Customization

Make a chat comfortable to read. Appearance changes the whole Nativ app; chat text size changes only message and composer text.

## 1. Open General settings

Select the **gear** at the bottom of the sidebar, or press `⌘,`. In **General**, find **Appearance** and **Chat Text Size**.

{% image src="/assets/getting-started/customization/01-general-settings.png" alt="Nativ General settings showing Appearance and Chat Text Size" caption="Both reading controls are in Settings → General." /%}

## 2. Try the changes

Choose **System** to follow macOS, or choose **Light** or **Dark** to keep one appearance. Drag **Chat Text Size** until a conversation is easy to read. Changes appear immediately, so you can compare them with a chat open.

The preview below shows the same conversation in both appearances and at three representative sizes. Try it before changing Nativ if you are unsure which you prefer.

{% chatdemo /%}

Nativ has five text-size stops from **85%** to **150%**; the preview shows **Small**, **Default**, and **Large**. You can also press `⌘+` or `⌘−` in Nativ to change chat text size, or `⌘0` to return to 100%.
