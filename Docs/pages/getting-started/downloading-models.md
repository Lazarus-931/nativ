# Downloading Models

Download one model before your first chat. You can add more later.

## 1. Open Models

Select **Models** in Nativ's sidebar, then open **Discover**.

{% image src="/assets/app-sidebar.png" alt="Nativ sidebar with Models selected" width=340 caption="Models is the place to discover and manage local models." /%}

## 2. Find a model

Browse the list or search by name. Check its capability tags and size; a smaller model is a practical first choice if your Mac has limited unified memory.

{% image src="/assets/models-discover.png" alt="The Discover view with model search, filters, and model rows" caption="Search or filter the Discover list to narrow your choices." /%}

## 3. Check its details

Select a model to read its description and see its size, license, and other details. Choose one that fits your Mac and your task.

{% image src="/assets/models-detail.png" alt="A model detail panel showing its description and information before download" caption="Inspect the model before committing to a download." /%}

## 4. Download it

Select **Download** and wait for the progress bar to finish. The model then appears under **Installed**, ready to select for chat.

{% image src="/assets/models-download.png" alt="A model downloading in Nativ with visible progress" caption="You can watch progress, pause, or cancel the download." /%}

Next, [start the server](/getting-started/starting-server).
