# Get Started

Nativ runs AI models locally on an Apple-silicon Mac. No account is required. Follow these guides in order to go from a fresh installation to your first conversation.

{% showcase title="Guided setup" image="/assets/onboarding-welcome.png" alt="Nativ's welcome screen at the start of guided setup" href="/getting-started/installation" cta="Install Nativ" %}
When you first open Nativ, guided setup helps you choose a model and prepare the local server.
{% /showcase %}

{% steps %}
{% step title="Installation" href="/getting-started/installation" %}
Install the app on a Mac with Apple silicon and macOS 26 or newer.
{% /step %}
{% step title="Downloading Models" href="/getting-started/downloading-models" %}
Find a model that fits your Mac and download it.
{% /step %}
{% step title="Starting Server" href="/getting-started/starting-server" %}
Start Nativ's local runtime and check that it is live.
{% /step %}
{% step title="Your First Chat" href="/getting-started/first-chat" %}
Send a prompt and read your first locally generated answer.
{% /step %}
{% step title="Customization" href="/getting-started/customization" %}
Adjust appearance and chat text size for comfortable reading.
{% /step %}
{% /steps %}
