# Artifacts

This walkthrough shows how to find a file from an earlier chat and return to the conversation around it. Nativ collects supported files you upload or generate in chats automatically.

## 1. Open the gallery

Select **Artifacts** in the sidebar. The gallery brings images, videos, and documents from different chats into one place.

{% image src="/assets/features/artifacts/01-artifacts-gallery.png" alt="The Artifacts gallery with a research paper, storefront photo, urban fox photo, and generated coastal research station" caption="Uploaded and generated files appear together; you do not import them again." /%}

## 2. Find the right chat

Open **Group by** and choose **Chat**. Related files become stacks. In this example, select the **Kimi K3 paper review** stack to narrow the gallery to that conversation.

{% image src="/assets/features/artifacts/02-group-by-chat.png" alt="Artifacts grouped into chat stacks including Kimi K3 paper review" caption="Grouping keeps a paper with the chat where you discussed it." /%}

## 3. Preview the file

Select the paper. Nativ opens its PDF preview without leaving the gallery, alongside the prompt that introduced it.

{% image src="/assets/features/artifacts/03-preview-pdf.png" alt="The Kimi K3 paper open in Nativ's artifact preview with an Open in Chat button" caption="Check the file and its original prompt before returning to the conversation." /%}

## 4. Return to its context

Select **Open in Chat**. Nativ opens the source chat at the message containing the paper, so you can continue the work instead of searching for that message manually.

{% image src="/assets/features/artifacts/04-open-in-chat.png" alt="The Kimi K3 paper review chat opened at the message containing the paper" caption="Open in Chat restores the question and answer around the file." /%}
