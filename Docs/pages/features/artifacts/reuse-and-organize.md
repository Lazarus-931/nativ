# Reuse and Organize

Open **Artifacts**, then Control-click a file to see the actions available for that item.

## Use a file again

Choose **Use in Chat** to attach an image to a new conversation, or **Use as Image Reference** to start new image work from it. Choose **Open in Default App** when you need to work with the file outside Nativ. **Share**, **Export**, **Copy**, and **Reveal in Finder** provide other ways to move it into your workflow.

## Keep it easy to find

Choose **Add to Favorites** for a file you use often. **Rename** changes its display name in Nativ, not the underlying filename. To act on several files, choose **Select** above the gallery and select the items you want to share, export, or delete.

## Delete only when finished

Deleting an artifact removes its stored file **and** removes it from the associated chat history. This cannot be undone. Export anything you need before confirming deletion.

For search, grouping, and sorting options, see [Artifact gallery controls](/features/artifacts/controls).
