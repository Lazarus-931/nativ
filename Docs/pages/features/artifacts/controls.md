# Gallery Controls

Use these controls when the gallery contains more files than you can comfortably scan.

| Control | What it does |
| --- | --- |
| **Grid View / List View** | Switch between thumbnails and filename-focused rows. |
| **Images / Videos / Documents / Favorites** | Show one kind of artifact or only items you favorited. |
| **Group by → Chat** | Stack artifacts from the same chat. Grouping is unavailable while a search is active. |
| **Group by → Source / Date** | Narrow the gallery by where a file came from or when it was added. |
| **Sort** | Order results by newest, oldest, name, size, or type. |
| **Search** | Match filenames and prompts. With Smart Search and its on-device embedding model installed, it can also match by meaning. |
| **Clear All Filters** | Return to the full gallery. |

In a preview, use the left and right arrows to move through the current results. Pinch to zoom an image. For the basic path from a file back to its conversation, follow the [Artifacts walkthrough](/features/artifacts).
