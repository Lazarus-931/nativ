# Audio controls

Use this page to find a control after you have [made your first recording](/features/audio). You do not need to configure every tab before using Audio.

| Tab | What it controls |
| --- | --- |
| **Record** | Microphone, input level, system audio, Auto-summary, and optional meeting transcription suggestions. **Complete** saves the current take; **Restart** begins again; **Delete** discards it. |
| **Library** | Saved recordings and recent dictations. Play audio, read or copy a transcript or summary, rename a recording, retry transcription, or reveal its file in Finder. |
| **Model** | Choose **Automatic** or a specific installed speech-to-text model. **Find models** appears when none is available. Summaries require a language model as well. |
| **Shortcuts** | Change the global dictation and retry shortcuts. **Hands-free** switches dictation from hold-and-release to tap-to-start and tap-to-stop. |
| **Animation** | Choose how dictation and recording appear while active, and select a capture sound. |
| **Overview** | Review local dictation activity, including words dictated, average speed, estimated time saved, and recent activity. |

For the difference between saved recordings and temporary dictation audio, read [How Audio handles your recordings](/features/audio/recordings-and-privacy).
